# 대시보드 상태와 기능 조작

기존 감지–관측–조작 영역과 오프라인 단일 HTML 구조를 유지한다. 상단에는 배터리·보정·위치·동작을 배치하고, 오른쪽에서만 로봇 명령을 실행한다. 모바일에서는 지도 다음 조작 영역을 배치한다.

배터리는 설정 가능한 battery_topic(기본 /battery_state)의 실제 BatteryState만 사용한다. 유효한 잔량이 없으면 전압으로 추측하지 않으며, 미수신·미연결·수신 지연을 구분한다. 카메라 스위치는 이 브라우저의 영상 다운로드와 표시를 제어하며 카메라 전원 제어라고 표시하지 않는다.

지도 수집 중지는 자동 주행 정지 요청 후 SLAM pause 서비스와 readback으로 확인한다. 기존 지도는 보존한다. 재개 시 자동으로 주행을 시작하지 않는다. 주행과 비상정지는 HTTP 성공 외에 이후 ROS 상태 수신을 확인하고, 확인되지 않으면 시간 초과로 표시한다.

검증은 domain 231의 실제 WebNode HTTP 서버와 별도 ROS 테스트 노드로 수행한다. 가상 배터리와 SLAM 서비스임을 기록하고, 물리 로봇에는 연결하지 않는다. 스크린샷 전후 비교, 데스크톱·모바일, 서비스 거부, 배터리 유실, 영상 요청 중단, 주행 및 비상정지 수신을 검사한다.
