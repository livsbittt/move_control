# 장애물 추적 및 지도 검증

사용자가 승인한 순서: 장애물 발견 → 자기 움직임 보상 → 정지/이동/불명 분류 → 대기 또는 정지 장애물 우회 → 원래 경로 복귀.

## 구현 및 검증 순서

1. 최신 main의 회귀 테스트와 지정 월드 매핑 기준 실행을 확인한다.
2. ROS 비의존 추적기를 구현한다. 같은 좌표계의 연속 관측, 시간 순서, 데이터 연관 모호성, 추적 소실을 명시적으로 다룬다.
3. 센서 타임스탬프의 TF로 LiDAR 관측을 odom 좌표계로 변환한다. 카메라는 물체/가림 보조 증거로 사용하고 단안 영상에서 검증되지 않은 미터 거리를 만들지 않는다.
4. 안전 게이트와 주행 FSM에 충돌 예상/관측 불명 대기를 연결한다. 정지 장애물은 관측된 여유 공간을 통한 경로 재계획으로 처리한다.
5. 지정 월드의 정지·횡단·접근·가림 장애물 시험을 수행한다. 별도의 로컬 장애물 정보와 영구 SLAM 지도 오염을 평가한다.
6. 실제 센서 입력, 최소 간격, 속도, 정지 지연, 지도 미관측 비율/벽 재현율/유령 장애물 비율과 원래 경로 복귀를 기록하고 맵을 저장한다.

## 완료 조건

테스트용 합성 카메라와 실제 Gazebo 렌더 카메라를 구분한다. ground truth는 판정에만 쓰고 운영 추적기의 관측 입력에 넣지 않는다. 지도 완성은 기존 전체 월드 기준 감사로 판정한다. 실패나 부분 관측을 완성으로 표기하지 않는다. 실기 배포는 이 검증에 포함하지 않는다.

## 현재 발견

기존 Gazebo adapter는 카메라/IR 합성이므로 카메라 인식 검증에 그대로 사용할 수 없다. 기존 매핑 자료도 원본 미로 전체 완성을 증명하지 않는다. 최신 main 07f6661을 기준으로 별도 브랜치 codex/dynamic-obstacles에서 작업한다.
