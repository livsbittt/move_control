# 지도 화면 각도 정렬

- 지도 화면이 기울어져 보이는 문제는 표시 좌표계에서 처리한다. ROS 지도,
  TF, 센서 방향, 경로 및 전송하는 목표 좌표는 변경하지 않는다.
- 첫 유효 위치의 yaw로 화면을 한 번 정렬한다. 이후 로봇의 회전은 화면 각도를
  바꾸지 않는다. 지도 초기화 시 기준을 다시 잡는다.
- 방향 정렬 버튼은 현재 yaw를 다시 기준으로 선택한다. 좌우 버튼은 5도씩
  조절하고, 0도 버튼은 원래 지도 방향으로 복원한다.
- 지도 이미지와 모든 오버레이에 같은 회전을 적용한다. 클릭·휠 확대·드래그에는
  역회전을 적용하여 화면의 선택 지점과 ROS 목표 좌표를 일치시킨다.
- 현재 웹 관측값은 약 -22.9도다. 고정 30도 보정이나 SLAM TF 수정은 하지 않는다.
- 검증: 각도별 좌표 왕복, 정렬된 방향, 확대 중심 보존 단위 테스트와 실제
  Playwright 버튼 조작 및 화면 캡처. 주행 정확도 검증은 포함하지 않는다.
