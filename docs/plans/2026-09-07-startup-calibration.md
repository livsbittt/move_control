# 시작 시 센서 보정·검증 절차

## 실행 순서

`startup_calibration_node`는 시작 시 이전 통과 상태를 무효화하고 정지 측정을
자동으로 시작한다. LiDAR, odometry, 바닥 IR 3개, IMU, 초음파, 카메라,
센서 장착 TF, 지도, 지도 내 로봇 TF를 점검한다. 빠른 센서는 최소 20표본,
3초 이상의 안정 구간을 요구하며, 느린 지도는 최신 유효 메시지를 확인한다.

정지 측정 후 `waiting_motion` 상태에서 명시적인 이동 검증 요청을 받는다.
비상정지가 해제돼 있고 안전 신호와 지도/센서가 유효해야 시작한다.
기존 주행 노드의 정지를 확인한 후 안전 게이트를 통해 초속 8mm로
최대 4초 또는 4cm를 이동한다. 전진 방향, 옆으로 흐르는 정도, 회전,
LiDAR/초음파의 벽 거리 변화 및 지도 위치 변화를 비교한다.

성공 후에만 `/calibration/ready`가 참이 된다. 결과와 기준 측정값은
`~/.local/state/move_control/calibration.json`에 원자적으로 저장한다.
저장된 이전 결과가 재시작의 검증을 대신하지 않는다.

## 웹과 주행 차단

대시보드는 단계별 이유와 각 센서 상태를 표시한다. 재시도, 이동 검증,
중단 버튼을 제공한다. 일반 주행과 수동 이동은 검사 통과 전 차단한다.
주행 노드는 보정 결과 heartbeat가 3초 이상 끊기면 정지한다.
지도 초기화 시 보정도 재시작한다. 비상정지는 자동으로 해제하지 않는다.

## 보정의 범위

이 절차는 현장 기준 측정과 센서 간 일치 검증이다. 한 번의 짧은 이동으로
카메라 내부 파라미터, 휠 직경/축간 거리, IMU 전체 바이어스 모델이 정확히
식별되는 것은 아니다. 안전 거리나 절벽 임계값을 자동으로 낮추지 않는다.
LiDAR 방향은 독립적인 수동 숫자 대신 실제 장착 TF를 사용한다.

## 실행

업데이트된 패키지에서 `robot.launch.py`는 보정 노드도 실행한다.
센서·SLAM·안전 노드가 이미 실행된 환경에서 보정만 시작하려면:

```bash
ros2 launch move_control startup_calibration.launch.py
```

실물 동작 중 기존 프로세스와 중복 실행하지 않는다.
