# 원본 트랙 자율 주행 복구

목표: 원본 `map_260905.world`의 접근 가능한 구역을 Gazebo에서 보정 후 자율 탐색한다. 안전 게이트, 속도 한계와 원본 벽은 유지한다. 밀폐 삼각형은 탐색 가능 구역과 구분한다.

확인된 원인:

1. 코너 도달 판정이 코너까지의 반경 거리여서 코너를 떠난 뒤 이전 코너를 다시 목표로 삼는다. 기존 4cm 허용값은 좁은 경로의 회전 여유까지 소진한다.
2. 시뮬레이션 바퀴 관절은 회전된 child 프레임의 Y축을 사용해 실제 실린더 회전축 Z와 어긋난다. SDFormat joint/axis 기본 좌표계 규약에 따라 수정한다.

수행:

- 코너 폐루프 회귀 테스트를 먼저 실패시킨 후 진입 선분 진행량과 5mm 코너 허용값으로 수정.
- 바퀴 축 회귀 테스트를 먼저 실패시킨 후 generator와 생성 SDF를 함께 수정.
- 새 보정으로 수정된 wheel 모델 실행. 경로, 최종 속도, 안전 정지, 지도와 접근 가능한 구역의 미탐색을 관찰. 추가 실패는 입력/판단/출력 근거를 확보한 뒤 수정.
- 전체 테스트, 코드 리뷰, 실행 증거를 확보하고 커밋·main 통합. 원본 전체 100%와 실물 하드웨어 성공을 혼동하지 않는다.

참조: https://sdformat.org/spec/1.11/joint/ (axis는 기본 joint 프레임, joint는 기본 child link 프레임).

## 센서 기반 회전 영역

- 회전 반경을 차체 중심의 고정 숫자로 보지 않는다. 신뢰할 수 있는 충돌 형상에서 외곽을 얻고, 정지된 좌우 보정 끝점의 LiDAR 정합 이동량으로 회전 중심을 추정한다. 오도메트리와 IMU의 회전·이동 일치를 함께 확인한다.
- 스캔의 빔 간격을 이동량으로 오해하지 않도록 관측된 벽 선분에 정합한다. 회전 자극량과 잔차, 좌우 반복 간 차이를 불확실성으로 보존한다. 이것은 센서 일관성 추정이며 보장된 오차 한계나 물리 안전 인증이 아니다.
- 안전 게이트는 동일한 회전 중심으로 장애물 거리와 차체 외곽의 회전 영역을 비교한다. 만료·취소·형상 불일치 후에는 회전 허가를 보류한다. 관측이 빠진 LiDAR 방향은 빈 공간으로 취급하지 않는다.
- 초음파는 전방 거리 일치와 접촉 방지를 담당한다. IR은 바닥 위험, IMU는 자세·회전, 카메라는 상태 관측을 담당한다. 단안 RGB나 IR ADC로 보이지 않는 차체 치수를 만들어내지 않는다.
- Gazebo의 보조 센서는 일부 합성 입력이다. 바퀴 접촉 모델 검증과 실제 Pinky 센서 독립성·실물 검증은 구분한다.

## 추가 복구 수정

수락한 대체 경로의 과거 실패 출구를 제거한다. 이후 경로가 취소되면 현재의 빈 경로 상태를 기록하여 새로운 경로가 오래된 실패 출구에 막히지 않게 한다. 선호 경로 여유와 최소 안전 재탐색 여유를 분리한다.
