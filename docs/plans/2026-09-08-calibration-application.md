# 보정 프로파일 적용과 회전 검증

기준 커밋 `856ea53`, 작업 브랜치 `codex/rotation-calibration`.
2026-09-08 사용자 승인에 따라 격리 워크트리에 코드 적용. main 통합과 실기 배포는 별도이다.

## 적용된 동작

1. `/calibration/profile`은 회차 ID, 증가하는 sequence, 발행 시각, 1.5초 유효기간, 적용 범위, 전후진 배율, 회전 결과, 기체 설정 revision을 한 메시지에 포함한다. 기존 `drive_scale`/`ready` 조합은 보정값 적용 권한이 없다.
2. safety가 검증한 프로파일을 `/calibration/applied`로 확인한다. startup은 자신의 회차·revision과 일치하는 최신 확인이 있어야 ready를 발행한다. 검증 실패/만료 시 기본 배율로 돌아가며, 마지막 정상 revision은 진단용으로 보존한다. 만료된 이전 결과를 자동 재활성화하지 않는다.
3. 보정 시작 시 기체 설정을 고정한다. 반경, 거리, 라이다 방향, 모터 부호, IMU 단위가 바뀌면 다시 보정해야 한다. 안전 노드가 시험 명령을 감속/변경하거나 0.2초 안에 명령을 확인하지 않으면 시험을 중단한다.
4. 센서 원본 시각과 수신 후 경과 시간을 함께 적용한다. 같은 stamp의 재전송은 표본 수를 늘리지 않는다. LOOK의 전후좌우 거리 표본은 동일 라이다 generation의 묶음에서 한 번만 수집한다. 카메라 및 다른 advisory 값까지 동시 관측임을 보장하는 전체 snapshot은 아니다.
5. 직선 검증 이후 `+10° → 원점 → -10° → 원점`을 두 번 수행하는 회전 시험을 연결했다. 초기 요청 각속도는 0.06 rad/s, 배율 허용 범위는 0.75~1.25이다. 회전 시 라이다의 제한된 각도 탐색 결과와 IMU·오도메트리 상대각을 비교한다. 좌우 응답 및 반복 일치, 원점 복귀, 병진 이동 8 mm 한계, 정지 대기, 시간 한계를 확인한다.
6. 라이다 회전 추정은 순수 회전에 가까운 조건의 polar alignment이다. 360~1440개 전주기 표본, 90% 이상 대응, 잔차 및 다른 후보와의 차이를 확인하며 원형 공간 등 방향을 구분할 수 없는 환경은 거부한다. 실제 시험 시작은 전방향의 유효 거리와 차체 여유를 요구한다. 충분한 공간이나 관측성이 없으면 실패 상태로 남는다.
7. 검증된 회전 배율은 0.06 rad/s 이하 순수 회전에만 적용한다. 직선 배율은 저속 직선에만 적용하며 곡선에는 두 값을 조합하지 않는다. 모든 최종 명령은 최대속도와 공간별 감속 제한을 다시 통과한다.
8. 공간별 감속은 차체 주변 2 cm 여유 구간과 전후방 gap을 사용하는 보수적 정책이다. v와 omega를 함께 줄여 곡률을 유지하고, 미확인 여유를 열린 공간으로 취급하지 않는다. 지도 주행의 진행량은 전체 시간창의 순변위를 평가하여 작은 반복 왕복으로 정체 예산이 계속 초기화되지 않게 했다.
9. 대시보드는 safety의 실제 stop/clear/radius를 받아 표시하며, 적용 확인 대기, 회전 8구간 진행, 최종 제한 사유, 물리 검증 미완료를 구분한다. 오래된 프로파일은 현재 적용 여부 미확인으로 표시한다. 다른 게이지 설정은 기존 구성값이다.

## 검증

- 격리 ROS Jazzy Docker, 네트워크 차단: `test/`, safety/startup/wander calibration ROS 테스트, web calibration HTTP 테스트 **249개 통과**.
- dashboard JavaScript 테스트 **15개 통과**.
- `colcon build --packages-select move_control` 통과.
- 독립 리뷰에서 발견한 기체 revision 재부착, 회전 중 wander 개입, source age 연장, 저장 결과 누락, 환경 감속의 gain 오인, 잘못된 JSON 형태 문제를 수정했다.
- 합성 센서로 8구간 회전 → 최종 프로파일 저장 → SafetyNode 검증 → 일치하는 적용 확인 → ready 경로를 검증했다. 실제 모터 응답의 검증 결과는 아니다.
- 현재 브라우저 연결 목록이 비어 있어 실제 브라우저 렌더링 검증은 수행하지 못했다.

## 실측이 필요한 범위

10°/0.06 rad/s 및 정합 허용치는 현재의 제한된 시험 후보이다. 실제 기체의 관측성과 센서 오차에 맞는지 보호된 실기에서 확인해야 한다. 보정된 배율만으로 물리 반경, 지지 footprint, 제동거리 또는 안전 인증을 추정하지 않는다.

공간별 감속은 **현재 실제 속도에 따른 정지 궤적 모델이 아니다**. 실제 속도·제동 응답·최악 지연을 측정한 뒤 stopping sweep과 불확실성 여유를 추가해야 한다. 실측 전에는 차체 반경과 기본 안전거리 하한을 축소하지 않는다. 전체 명령 소유권 lease, 완전한 다중 센서 snapshot, ARM64 시간 측정, 실기 주행 및 통합 브랜치 검증은 남아 있다.
