# 실기 탐색·회전 복구 기록

대상은 ?? ??의 Rosy Control이다. 소스 테스트와 실제 주행 결과를 구분한다.

## 확인된 원인과 적용

- 지도 서비스가 SLAM만 실행해 `/goal/cmd`를 처리할 계획 노드가 없었다.
  `map.launch.py`에 정지 상태의 계획 노드를 포함하고 `start_goal:=false` 선택도 제공한다.
  기존 dashboard launch의 별도 계획 노드와 중복되지 않도록 처리했다.
- 일부 센서 모드의 최종 선속도 5mm/s를 요청 속도 14mm/s와 비교해 정체로 오판했다.
  최신 최종 명령 속도로 기대 이동량을 계산한다. 실제 정체와 세션 제한은 유지한다.
- 회전 보정은 직선 시험의 회전 금지 상태가 남은 순간 공간 부족으로 실패했다.
  새 회전 프로필의 세션·리비전 및 게이트 시험 상태 응답을 정지 상태에서 기다린다.
- 안전 거리 정보가 바뀌어도 출발 전 30mm 목표가 고정돼 실패했다.
  출발점을 기록하기 전만 최신 여유에 맞춰 목표를 줄이고, 출발 후에는 고정한다.
- 코너에서 0.3rad 경계의 정렬/전진 전환이 반복됐다. 정렬에 들어가면 0.2rad까지
  맞춘 뒤 전진한다. 전진 차단 기준 0.3rad는 유지한다.

## 실기 증거

- v6: LiDAR를 포함한 정지 센서 검사와 3cm 왕복 2회 통과. 회전 첫 구간까지
  실제 진행했지만 전체 명령량/실측량 보정비 검사에서 실패했다. 전체 보정 성공이 아니다.
- v6 정보량 우선: HTTP 202, 경로 14개 수신(최대 32점), 정렬/전진 및 목표 도달 이벤트,
  odom 변위 17.894mm. 최종 속도 최대 5mm/s, 0.05rad/s. 20초 시간 제한으로 정지했다.
  지도 수신은 유지됐지만 이 짧은 시험에서 관측 셀 수는 495로 동일했다.
- 회전 응답 별도 검사: 좌우 각각 0.06rad/s를 약 3초 입력했다. 최종 명령 적분은
  +0.18356/-0.17763rad, odom +0.14653/-0.13231rad, IMU +0.13655/-0.13351rad였다.
  응답 시작 지연 약 0.29~0.49초를 포함하므로 전체 비율을 일반 회전 이득으로 적용하면 안 된다.
  중앙 구간 odom 속도는 약 0.053rad/s로 Dynamixel 정수 속도 단위의 예상치와 가깝다.
- v8에서 세 방법을 각각 20초씩 실제 실행했다. 모두 HTTP 202와 경로 발행,
  실제 회전/전진, 시간 제한 정지를 확인했다. 각 시험의 최종 속도 상한은 동일했다.

| 방법 | odom 변위 | 경로 수 / 최대 점 수 | 관측 지도 셀 |
| --- | ---: | ---: | ---: |
| 정보량 우선 | 66.889mm | 12 / 32 | 495 → 756 |
| 가까운 곳 우선 | 66.776mm | 12 / 41 | 756 → 805 |
| 영역 순회 | 30.140mm | 12 / 9 | 805 → 817 |

이는 제한된 시간의 주행과 지도 확장 증거이며 영역 전체 탐색 완료를 뜻하지 않는다.
v9 회전 검증은 시작 지연과 중앙 구간 지속 응답을 분리한다. 보정 이득 적용 검증은
별도이며 `compensation_verified=false`, 운행 이득 `[1,1]`을 유지한다.

## 운영 상태

기존 지도를 유지하기 위해 SLAM을 재시작하지 않고 임시 `rosy-session-goal` 유닛을
연결했다. 지도 서비스 종료 시 이 유닛도 종료된다. 이후 지도 시작은 새 launch가 맡는다.
각 실제 시험은 종료 시 주행 정지와 비상정지를 적용하고 원격 상태 파일에 결과를 저장한다.
수동 보정 완료 모드와 독립 센서로 검증된 보정, 응답 측정과 보정값 적용 검증을 구분한다.

## v14 실기 재확인

- 로컬 및 로봇에서 registration endpoint / rotation envelope 테스트 각각 23개 통과.
  실제 점군의 부동소수점 끝점 오차를 처리하고, 점 대응으로 초기 이동량만 추정한다.
  최종 선분 지지율·기하 관측성·잔차 기준은 유지한다.
- 독립 회전 진단에서 첫 약 10도 구간의 응답 및 위치 추정을 통과했다.
  LiDAR 위치 추정 잔차는 1.02mm였다. 이후 각도 정합이 끊겨 정지했다.
  양방향 전체 반복 및 회전 중심 보정 완료를 의미하지 않는다.
- 지도 계획 노드를 다시 연결하고 정보량 우선 탐색을 20초 실행했다.
  HTTP 202, 경로 12회, odom 변위 19.856mm, 관측 셀 543→771을 확인했다.
  최종 명령 상한은 5mm/s 및 0.05rad/s였고 시간 제한으로 정지했다.
  증거는 로봇 상태 디렉터리의 `navigation-motion-gain-v14.json`에 저장했다.
- 직전 진단 도중 다른 대시보드 클라이언트의 `retry:stay`가 들어온 사실은
  `operator_request` 로그로 구분했다. 이후 재시험은 별도로 수행했다.
