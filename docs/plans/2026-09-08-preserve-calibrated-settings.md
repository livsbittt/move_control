# 초기 기본값과 기존 설정 보존

사용자 지시: 고정값은 초기값으로만 사용하고 기존 설정이나 보정 결과를 덮어쓰지 않는다.

다른 세션의 `codex/roundtrip-ui-integration` (`5fff349`)에서 환경별 여유거리 및 방향별 차체 계산을 확인했다. 해당 워크트리는 수정하지 않았다. 양쪽에 남아 있던 기존 `calib_node.compute()`의 고정 설정 재저장 경로를 현재 `codex/rotation-calibration`에서 제거했다.

- `calib_node`는 실제 측정한 IR 임계값·모터 부호·IMU 기준·라이다 방향만 저장/전달한다. 미측정 라이다 방향에 기본 방향을 다시 기록하지 않는다.
- 정지/해제 거리, 초음파 거리, 반경, 카메라 정책, 전방 각도, cliff 활성화 및 hit 수를 보정 완료 때 고정값으로 다시 쓰지 않는다. 초기 기본값은 기존 parameter 선언 및 robot.yaml에서 제공한다.
- YAML을 전체 교체하던 저장은 기존 node/parameter 항목을 보존하는 병합으로 변경했다. 실제 파일 교체는 임시 파일과 os.replace를 사용한다. 기존 YAML이 잘못되어 읽을 수 없으면 보존하고 저장 실패를 반환한다.
- `SafetyProfile`은 누락된 stop/clear에만 초기값을 채운다. 명시된 유효값은 그대로 사용한다. 추가 floor의 기본값은 0이며, 기본 정지거리 0.12/0.14를 매 tick 강제하지 않는다.
- 물리 형상 및 명시적 제약 검증은 남긴다. 부적합한 값은 임의로 수정하지 않고 profile invalid로 판정하여 정지한다. 기존 설정의 .018/.028 또는 8도 cone이 남아 있다면 보정 재실행이 이를 자동 수리하지 않는다. 유효한 구성으로 별도 갱신해야 한다.

회귀 검증: 기존 파일의 미측정 값·사용자 추가 키 유지, 측정한 모터 부호만 변경, malformed YAML 보존, 반복 tick 이후 .115/.13 유지, 물리 조건 위반 거부. 독립 리뷰에서 신규 차단 이슈 없음.

이 수정은 다른 세션의 환경별 설정 계산을 가져오거나 대체하지 않는다. 추후 통합 시 그 계산 결과가 설정 보존 및 검증 계약을 통과하는지 다시 확인한다.
