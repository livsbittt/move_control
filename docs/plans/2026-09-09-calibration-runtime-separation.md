# 보정 결과 유지와 주행 점검 분리

보정 완료 기록은 센서 수신 상태와 별도로 유지한다. 주행 중 센서 지연은
현재 주행 허용을 중지하지만 저장된 보정 결과를 삭제하거나 정지 보정을 시작하지 않는다.
필수 센서가 회복되면 기존 보정값으로 준비 상태를 회복한다. 중단된 자율 주행은
새 시작 요청을 기다리며 임의로 재개하지 않는다.

- `calibration_complete`: 완료한 보정 절차 또는 명시적 수동 운행 선택.
- `calibration_verified`: 실제 보정 검증 완료 여부. 수동 선택은 false.
- `ready`: 현재 수신 상태와 최종 안전 노드 적용 응답을 포함한 운행 허용.
- `runtime_state`: ready, sensor_hold, recalibration_required 등 현재 점검 상태.
- `recalibration_required`: 유효한 최신 설정이 검증한 보정 대상 식별자와 달라진 경우.

지도와 지도 위치는 지도 기반 운행에 필요하다. 지도 사용을 요구하지 않는 운행의
보정 결과를 지도 수신 지연만으로 무효화하지 않는다. 완료 상태에서는 정지 벽 추정과
보정용 점군 생성도 수행하지 않는다. 명시적 재보정 요청은 기존 인증서를 무효화한다.
단순 센싱/기존값/일부 센서 모드 전환은 인증서를 삭제하지 않는다.

## 정밀 보정 수정

회전의 초기 응답 지연과 지속 응답 비율을 구분해 저장·검증한다. 검증되지 않은
각속도 보상은 적용하지 않는다. 라이다의 연속 네 관측점이 지지하는 직선도 사용해
짧은 선분 방향의 양자화 오차를 줄이며 최종 지지율·잔차·기하 관측성 기준은 유지한다.
정합 실패 시 정지 후 제한된 원시 스캔과 거부 사유를 저장한다.

SLAM의 전역 지도 보정은 지도 위치 일치 여부로 별도 기록한다. 바퀴 보정은 독립적인
라이다 이동량, 바퀴 이동량, 방향·횡이동 한계, 보상 후 왕복 반복 결과로 판정한다.
지도 좌표 변화로 물리적인 이동 거리 검증을 대체하지 않는다.

## 지점 도착 전달

도착 알림이 계획 노드의 TF 수신 시차로 거절돼도 실제 도착 상태가 유지되면
현재 경로 식별자로 최대 초당 두 번 다시 전달한다. 계획 노드의 도착 거리와
발행 경로 검사는 유지하며, 다음 경로가 오면 전달 상태를 초기화한다.

## v16 실기 확인

실제 로봇에서 약 61.5초 동안 직선 왕복 2회(4구간), 좌우 회전 8구간을 모두
완료하고 인증서를 저장했다. 마지막 직선 원위치 오차는 -3.283mm,
전진/후진 보정 배율은 1.029353 / 1.053280이었다. 양방향 각각 두 개의
독립 끝점으로 회전 중심 추정도 통과했다. 각속도 보상은 적용하지 않는다.

저장 인증서 SHA256:
`131e1428bcdba610dc59576c2ac1ae4bc887da8978a10d2e7bf23b3111742703`.
로봇의 `calibration-v16-verified.certificate.json`에 별도 보관했다.
제어 서비스를 재시작한 후 `phase=ready`, `calibration_verified=true`로 복원됐다.
시작 직후 센서 대기는 `runtime_state=sensor_hold`이며 완료 증거는 유지됐다.

현재 서비스 시작은 `profile:=full start_imu:=false start_lcd:=false start_watch:=false
calibration_sensing_only:=false start_wander:=true`를 사용한다. 이전 sensing 프로필은
정지 전용 모드를 강제하므로 성공 인증서를 자동 복원하는 운행에는 사용하지 않는다.
실행 노드의 종류는 기존 선택과 동일하며 IMU는 별도 서비스가 담당한다.

v15 로컬 전체 테스트 815 passed / 1 skipped, 로봇 순수 로직 58개 및 ROS 노드
43개 통과. v16 출발 전 2초 zero 대기 수정은 로봇 순수 로직 24개 및 ROS 노드
43개를 통과했다.

## v17 연속 지점 이동

실제 도착 알림 30개가 경로 끝점의 2.739mm 지도 격자 이동 때문에 거절되는
경로를 재현했다. 발행한 경로의 실제 끝점을 발행 기록에 저장하도록 수정해
정확한 경로 식별 검증은 유지했다. 목표와의 5mm 일치, 실제 위치의 4cm 도착
거리 검사는 그대로다. 도착 거부 사유와 수락은 로그로 구분한다.

120초 실기 시험에서 목표가 (0.22,0.47) → (0.21,0.87) → (0.23,1.15)로
자동 전환되고 이후 전진하는 것을 확인했다. odom 시작/종료 변위 553.990mm,
경로 64회, 관측 셀 838→1007이었다. 92초 무렵에는 지도 장애물 여유 부족으로
경로 발행이 중단됐으며 120초에 시간 제한 정지했다. 이 후반 정지 원인은
도착 알림 대기와 구분해 확인 중이다. 전체 지도 탐색 완료를 의미하지 않는다.

보정 상태는 주행 후에도 ready/verified이고 인증서 해시도 같았다.
최종 로컬 전체 테스트는 820 passed / 1 skipped, v17 로봇 테스트는 19개 통과했다.
