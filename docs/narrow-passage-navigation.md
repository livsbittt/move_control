# 좁은 통로 탐색과 탈출

2026-09-08. 원본 `map/map_260905.world` 기준. 아래 설계의 통로 진입 정렬,
벽 선택 유지, 실패 입구 기억은 후속 통합 항목이다. 구현 여부를 설계와 혼동하지 않는다.

## 해결할 문제

진입 가능한 차체 폭과 제자리 회전에 필요한 공간은 다르다. 현재 주행에서는
회전 여유를 확보하도록 약간 후퇴한 뒤에도 작은 전진 조향에서 다시 회전 제한에
걸렸다. 모든 각속도 명령에 360도 회전 원을 요구하면 좁은 통로의 정상적인
방향 보정까지 막힌다. 반대로 제한을 단순히 낮추면 차체 모서리 충돌을 놓친다.

안전 판단은 세 가지로 나눈다.

| 동작 | 검사 대상 |
|---|---|
| 직진 진입 | 차체가 지나갈 구간과 정지 여유 |
| 작은 조향 | 실제 보정·제한된 속도 명령의 차체 궤적과 정지 여유 |
| 제자리 방향 전환 | 추정 회전 중심에 대한 전체 차체 회전 영역 |

`can_rotate`는 마지막 의미를 유지한다. 작은 조향 허용으로 바꿔 표시하지 않는다.

## 청소 로봇에서 가져올 동작 순서

1. **입구 정렬:** LiDAR의 여러 점으로 양쪽 벽 방향과 통로 폭을 추정한다.
   단일 좌우 거리 합은 사선 벽·출입구를 구분하지 못하므로 진입 방향의 근거로
   충분하지 않다. 관측 오차를 포함한 차체 통과 가능 여부를 확인한다.
2. **통로 통과:** 진입 방향, 목표 출구, 추종 벽을 유지한다. 미세한 지도 갱신으로
   좌우 벽을 번갈아 선택하지 않는다. 현재 센서와 제한된 궤적 검사는 계속 수행한다.
3. **진행 불가:** 실제 odom 진행량으로 정체를 판단한다. 제자리 흔들림과 명령을
   보냈다는 사실을 진행으로 세지 않는다. 횟수·시간 예산을 소진하면 정지한다.
4. **경로 후퇴:** 연속 odom으로 기록한 경로를 거꾸로 따라간다. SLAM 위치 보정
   점프는 후퇴 경로로 사용하지 않는다. 후방·측면·바닥 관측이 현재 안전해야 한다.
5. **회전 장소 도착:** 과거 회전 가능 상태가 0.5초 이상 확인된 위치를 목적지로
   사용하되 도착 후 현재 회전 여유를 다시 확인한다. 통로 안에서 U턴하지 않는다.
6. **재탐색:** 실패한 입구·진입 방향에 일시적인 비용을 부여해 다른 출구를 고른다.
   실행 실패를 SLAM 장애물로 덧칠하지 않는다. 새로운 관측이나 다른 접근 방향은
   재시도의 근거가 될 수 있다.

직사각형 전면의 청소 로봇이 들어갈 수 있지만 회전할 수 없는 좁은 공간과
후진 탈출을 구분하는 선행 설명은 [EP2570065 A1, 문단 0126–0129](https://data.epo.org/publication-server/rest/v1.2/publication-dates/20130320/patents/EP2570065NWA1/document.pdf)에 있다.
특허의 접촉 기반 동작을 탁상 Pinky에 그대로 적용하지 않는다.
[Nav2 BackUp](https://docs.nav2.org/rolling/configuration_and_development/configuration_guide/core_servers/bt_plugins/actions/BackUp/)
처럼 후퇴도 거리·속도·시간과 충돌 검사를 가진 별도 동작으로 다룬다.

## 현재 구현과 검증 범위

- `SafeTrail`: 실제 odom 경로와 회전 가능 위치 기록. 위치·각도 불연속, 센서 무효,
  시간 역행, 0.5초 초과 갱신 공백, 차체 교정 변경 시 기존 기록 폐기.
  저장 한도 2m/256점, 요청 후퇴 한도 기본 0.5m. 기록 자체는 이동 허가가 아니다.
- `TrailRetreat`와 Navigator: 정체 시 검증된 경로가 있으면 최대 6mm/s 후진한다.
  0.3rad를 넘는 방향 오차, 경로 이탈, 현재 센서 불가, odom 불연속은 정지한다.
  실패는 새 탐색 명령까지 유지하며, 한 탐색 명령당 후퇴 시도는 한 번이다.
  도착 지점의 현재 회전 여유를 확인한 뒤 재계획한다. 실행도 위 격리 시뮬레이션
  판정이 활성화된 경우에만 시작한다.
- `bounded_sweep_clearance`: 추정 회전 중심과 차체 외접 원을 사용한다.
  현재 위치부터 명령 유지 구간까지의 연속 궤적을 표본 사이 이동량으로 팽창시킨다.
  회전 중심 오차와 기존 10mm 여유를 포함한다.
- 안전 노드: 최종 보정·속도 제한 후 명령을 검사한다. 스캔은 수신 시각뿐 아니라
  원본 측정 시각도 0.2초 이내여야 한다. 스캔 지연과 이전 명령의 정지 잔여 이동은
  모든 방향의 추가 여유로 처리한다. 유효한 교정이나 전방위 스캔이 없으면 정지한다.
- 이 작은 조향 검사는 명시적으로 활성화한 `use_sim_time`, ROS domain 227,
  Gazebo partition `pinky_calmap227`의 바퀴 구동 시험에 한정한다. 물리 로봇 기본값은 꺼짐.

혼합 주행 4회와 단발 명령 중단 2회의 원시 자료는
`validation/2026-09-08-motion-contract/`에 있다. 단발 명령 후 안전 출력의 0 도달은
0.512–0.519초, 실제 속도 정착은 0.550–0.575초였다. 검사 유지 구간은 0.8초,
이전 명령 잔여 이동 여유는 최대 중심 속도 × 0.15초다. 짧은 시뮬레이션 관측에
기반한 설정이며 접촉·미끄러짐·실물 정지 성능을 보증하는 수치는 아니다.

## 완료 판정

좁은 직선, 비스듬한 입구, 막다른 길, L자 굴곡, 양쪽 출구 경쟁, 후퇴 중 새 장애물,
센서 끊김, odom 점프를 각각 재현한다. 입구 정렬→통과 또는 경로 후퇴→현재 회전
여유 확인의 전이를 기록하고, 실제 변위·최소 여유·재시도 횟수·충돌·지도 관측 면적을
비교한다. 전체 알고리즘을 통합한 반복 주행 증거가 나오기 전에는 탈출 완료로
표시하지 않는다. 원본 월드의 봉쇄된 공간은 단일 시작점에서 관측 가능한 면적과
구분하며, 맵 100% 완성으로 표시하지 않는다.
