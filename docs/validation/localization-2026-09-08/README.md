시간은 Gazebo 시뮬레이션 시각 기준이다. 시작 위치 `(2.55, 0.60, 0°)`에서 주행하고, `(0.45, 3.45, 90°)`로 옮긴 뒤 회전하고, 동일 위치에서 `-90°`로 다시 옮겼다. 위치 불명 중에도 시험 명령기가 `/cmd_vel_raw`로 전진 명령을 계속 보냈으며, 최종 safety가 차단했다. 라이다 중단 시 경로를 폐기했고 복구 후 실제 경로가 다시 생성된 것을 확인했다.

Gazebo 정답 pose는 오차 측정 전용이다. odom은 최종 안전 속도 명령을 적분하여 만들고, 순간 이동을 반영하지 않는다. AMCL 초기 후보는 지도/라이다 검색 결과만 사용한다. 저장 지도는 [기존 map.yaml](../../../map/calibrated_2026-09-08/map.yaml)을 그대로 사용한다.

ROS Jazzy 환경에서 `python3 -m pytest test/ -q`: **289 passed in 21.95s**. `colcon build`: **1 package finished**, 설치된 `localization.launch.py --show-args`에서 지도 인자와 시뮬레이션 시각 인자를 확인했다. 추가 테스트는 ROS 노드를 기동하지 않는 가짜 객체로 명령 캐시 유실/복구 순서를 검사한다.

한계: 기존 Gazebo 속도 플랜트와 합성 보조 센서를 사용한 시험이다. 실제 바퀴 odom, 미끄러짐, 실물 센서 노이즈와 RPi 처리 시간, 전체 wander FSM은 이 결과로 검증되었다고 주장하지 않는다. 대칭 공간은 추정 불명 상태를 유지하는 회귀 테스트로 확인했다. 실기기 배포는 수행하지 않았다.
