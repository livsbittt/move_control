# 원본 월드 주행과 좁은 통로 검증

원본 `map/map_260905.world`의 크기와 16개 벽을 유지했다. 원본 SHA-256은
`8475464857322d71f6e492171419bf285e7bd034089b90ad59d6f106b0941072`다.
물리 Pinky 로봇의 현장 검증은 이 자료에 포함되지 않는다.

## 변경 내용

- 센서의 회전 전후 변위로 회전 중심과 오차를 추정하고, 충돌 형상에 연결했다.
- 전체 회전 가능 여부와 짧은 조향 명령의 이동·정지 영역을 구분했다.
- 통과한 odom 경로와 회전 가능한 위치를 기록해 제한된 후퇴에 사용한다.
- 코너를 통과할 때 선택한 경로 구간을 유지하고, 후퇴 전후에는 그 기록을 초기화한다.
- 탈출 목표는 도착 확인까지 유지한다. 경로가 막히면 정지하며 탐색 목표로 바꾸지 않는다.

설계와 구현 범위는 [좁은 통로 탐색과 탈출](../../narrow-passage-navigation.md)에 있다.
실물에서 정지 성능을 측정하지 않은 작은 조향 검사는 격리 Gazebo 바퀴 모델에서만
명시적으로 활성화된다. 원본 하드웨어 LiDAR 식별 조건은 유지했다.

## 검증 기록

최신 실행 `4086f68e2c7e463eb9016f38ad6e85fb`의 결과는 **HOLD**다.
교정과 중앙 통로 이동은 확인했으나 오른쪽 통로에서 `trail_retreat_heading`으로
정지했다. 전체 탐색·후퇴 탈출·전체 지도 완성을 입증하지 못했다.

- 시작 코드는 `c0656d6`, 정지 후 wander만 `4922ae7`로 교체했다.
  교체 시각과 소스 구분은 `final-live/deployment.json`, 시작 소스 해시는
  `final-live/run_manifest.json`에 있다. 교체 후 명시적으로 탐색을 재개했다.
- 실시간 계수 0.3, 관측 시간 299.679 시뮬레이션 초, 총 이동 1.70654m.
  교정·정지·재개를 포함하므로 무중단 자율 주행 성적이 아니다.
- 지도 5,439칸 관측. 내부 미관측률 32.955%, 시작점과 연결된 점 공간의
  내부 미관측률 31.770%. 봉쇄 공간만으로 미완성을 설명할 수 없다.
- 최소 기준점–벽 거리 0.138899m. 이는 차체 전체의 최소 여유나 접촉 없음의 증명이 아니다.
- 최종 `/cmd_vel` 발행자는 `safety_node` 하나였다. 종료 명령 후
  `estop=true`, 속도 `[0,0]`, wander `stop`을 확인했다.
- 센서는 Gazebo LiDAR, GT 기반 odom/IMU, LiDAR 기반 초음파,
  합성 카메라/IR이다. 독립된 실물 센서 융합 검증으로 해석하지 않는다.
- 앞선 실시간 계수 1.0의 두 실행은 각각 LiDAR 교정 입력과 최종 안전 명령
  신선도 조건에서 중단됐다. 조건을 완화하지 않고 0.3으로 재실행했다.

무중단 자율 탐색의 성공 기록으로 해석하지 않는다.

`c0656d6-calibration-failure/`에 실패 증거를 보존했다.

## 검사

- Windows 순수 로직: 449 통과, 1 건너뜀.
- ROS 포함 전체 실행: 527 통과, 1 테스트 코드 오류. 잘못된 dataclass 사용을 수정한 뒤
  안전 게이트 파일의 18개 검사를 다시 실행해 모두 통과했다.
- 경로·회전·후퇴·계획 변경은 독립 검토를 거쳤다. 테스트 통과는 물리 로봇이나
  전체 월드 탐색 완료의 증거가 아니다.

## 지도 판정의 범위

원본 월드는 두 자유 공간 성분을 가진다. 봉쇄된 아래쪽 공간은 0.093024m²,
전체 자유 공간의 약 2.827%이며 한 시작점에서 진입할 수 없다.
시작점 연결 영역의 관측률을 전체 지도 완성률로 바꾸어 표시하지 않는다.

`footprint-topology.json`은 2mm 격자에서 반경 0.133388245m의 원형 근사 가용 공간이
좌우로 연결됨을 보여 준다. 직사각형 차체의 정확한 이동 가능성이나 센서 가시성을
증명하는 계산은 아니다.

화면 캡처는 실제 격리 실행의 대시보드다. `bounded-sweep-live/dashboard.png`는
`5c58fe4` 교정 후 주행 중의 부분 지도이며 최종 완료 화면이 아니다.
